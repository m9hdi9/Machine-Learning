# EV Sales Prediction - ARTI308 Lab 6

## About The Project
This project is part of my 3rd-year university Machine Learning lab (ARTI308). The goal is to build a **Linear Regression** model to predict Electric Vehicle (EV) sales using a dataset of EV and Petrol cars.

## Dataset
* **File:** `ev_vs_petrol_dataset_v3.csv`
* This dataset contains numerical data related to car sales, charging stations, and prices.

## Technologies Used
* **Python**
* **Pandas & NumPy** (For Data Manipulation)
* **Seaborn & Matplotlib** (For Data Visualization / EDA)
* **Scikit-Learn** (For Machine Learning / Linear Regression)

## Project Steps
1. **Data Loading:** Read the dataset into a Pandas DataFrame.
2. **Exploratory Data Analysis (EDA):** Visualize relationships and distributions using plots.
3. **Data Cleaning:** Remove missing values to prepare the data.
4. **Feature Engineering:** Select only numerical columns for the mathematical model.
5. **Modeling:** Train a `Linear Regression` model on the data.
6. **Evaluation:** Measure the model's accuracy using MAE, MSE, and RMSE metrics.
